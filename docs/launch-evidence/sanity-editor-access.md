## How to invite an editor (operational step — performed by founder)

1. Log into [sanity.io/manage/project/ho605hmx](https://sanity.io/manage/project/ho605hmx) with the founder account.
2. Go to **Members** → **Invite members**.
3. Enter the editor's email address.
4. Set role to **Editor**.
5. Click **Send invite**.

Once invited, each editor logs in at [bareter.sanity.studio](https://bareter.sanity.studio) with their own free Sanity account — no founder credentials are ever shared.

## Notes

Editors assigned the **Editor** role can create, edit, and publish all content types (hero, how-it-works steps, FAQ, help articles) but cannot access API tokens, webhooks, or project settings. This enforces least-privilege access.
