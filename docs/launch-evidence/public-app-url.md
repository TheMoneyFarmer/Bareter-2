# PUBLIC_APP_URL — evidence

**Status:** _UNFILLED — must be completed by the founder before public launch._

Audit artifact for Task #155 (set `PUBLIC_APP_URL` to the custom domain
in production). The code path is already in place — `baseUrlOf` in
`server/waitlistRoutes.ts` reads `PUBLIC_APP_URL` first, falling back
to `REPLIT_DOMAINS`, then `REPLIT_DEV_DOMAIN`, then localhost. See the
"Custom Domain & Outbound Links" section in [`../../replit.md`](../../replit.md).

This task only happens **after** Task #154 (custom domain + TLS) is
green. If the custom domain isn't live yet, do not set this secret —
leave it unset so links fall through to the working `*.replit.app` host.

> Common mistakes to avoid:
> - Trailing slash (`https://bareter.com/`) — `baseUrlOf` strips them,
>   but keep it clean.
> - `http://` instead of `https://` — would downgrade outbound links.
> - Setting it in the workspace dev env instead of the production
>   deployment env. Both have separate secret stores.
