
BARETER — Full Frontend Design Revamp
READ THIS ENTIRE PROMPT BEFORE TOUCHING ANY FILE.
This is Bareter, a UAE-based AI-powered barter marketplace. The stack is React 18 + Vite + Wouter + TanStack Query + shadcn/ui + Tailwind CSS. The backend is Express 5 + Drizzle ORM + PostgreSQL. Do not touch any backend files, agents, routes, or database schema. This is a frontend-only visual design revamp.
The current site exists and works. We are not rebuilding functionality — we are upgrading the visual design to feel like a premium UAE marketplace. Think Farfetch meets Dubizzle, built for Dubai in 2025.

9. UAE-SPECIFIC DETAILS

All currency: AED X,XXX format — never USD, never $, always AED prefix before the number
Location tags: Dubai · Abu Dhabi · Sharjah · RAK · Ajman · Fujairah · Al Ain
Date format: 12 May 2025 — not 05/12/2025 or American format
UAE flag emoji 🇦🇪 next to "UAE Verified" trust labels
Arabic RTL readiness: use CSS logical properties (margin-inline-start not margin-left, padding-inline-end not padding-right) throughout — even if Arabic is not active yet, the layout must not break when it is
Friday/Saturday = UAE weekend — any "active today" or "posted today" logic should reflect UAE timezone (Asia/Dubai, UTC+4)
High-value listing threshold: deals above AED 50,000 get a 🔒 Enhanced Verification badge on the card
