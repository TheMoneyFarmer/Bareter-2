ANIMATION 2 — Mouse parallax on hero
The floating cards respond subtly to mouse position. When the user moves their mouse across the hero, the card layers shift slightly — cards in the "back layer" move less, cards in the "front layer" move more. Creates depth.
tsx// Implement with a simple useMousePosition hook
// No heavy libraries needed — pure React + CSS transforms

const useMousePosition = () => {
  const [position, setPosition] = useState({ x: 0, y: 0 });
  useEffect(() => {
    const handler = (e: MouseEvent) => {
      // Normalise to -1 to 1 range relative to window centre
      setPosition({
        x: (e.clientX / window.innerWidth - 0.5) * 2,
        y: (e.clientY / window.innerHeight - 0.5) * 2,
      });
    };
    window.addEventListener('mousemove', handler);
    return () => window.removeEventListener('mousemove', handler);
  }, []);
  return position;
};

// Apply to card layers:
// Back layer (4 cards):  transform: translate(x * 8px, y * 6px)
// Front layer (2 cards): transform: translate(x * 18px, y * 14px)
// Headline layer:        transform: translate(x * 3px, y * 2px) — very subtle
// Transition: transform 0.1s ease-out on all — makes it feel smooth not laggy

// IMPORTANT: Disable mouse parallax on mobile (touch devices)
// Use: const isMobile = window.matchMedia('(hover: none)').matches

ANIMATION 4 — Listing cards entrance animation
When the listing card grid comes into view (user scrolls down to it), cards animate in from below with a staggered delay. Each card fades up one by one.
tsx// Use Intersection Observer — no library needed
// When the grid container enters viewport, add class 'in-view' to parent
// Children stagger in with CSS animation-delay

// CSS:
.listing-card {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 0.4s ease, transform 0.4s ease;
}

.listing-card.visible {
  opacity: 1;
  transform: translateY(0);
}

// Stagger delays: card 1 = 0ms, card 2 = 60ms, card 3 = 120ms, card 4 = 180ms
// Apply via inline style: style={{ transitionDelay: `${index * 60}ms` }}

// React hook:
const useIntersectionObserver = (ref, options) => {
  const [isVisible, setIsVisible] = useState(false);
  useEffect(() => {
    const observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        setIsVisible(true);
        observer.disconnect(); // only animate in once
      }
    }, options);
    if (ref.current) observer.observe(ref.current);
    return () => observer.disconnect();
  }, []);
  return isVisible;
};

// Apply to each card in the grid
// Once visible = true, add 'visible' class
// Disconnect after first trigger — animation only plays once per page load

ADDITIONAL MICRO-ANIMATIONS TO ADD EVERYWHERE

Trust bar counters:
When the trust bar scrolls into view, the numbers count up from 0 to their final value. Use a simple counter hook:
tsxconst useCountUp = (end: number, duration = 1500) => {
  const [count, setCount] = useState(0);
  useEffect(() => {
    let start = 0;
    const increment = end / (duration / 16);
    const timer = setInterval(() => {
      start += increment;
      if (start >= end) { setCount(end); clearInterval(timer); }
      else setCount(Math.floor(start));
    }, 16);
    return () => clearInterval(timer);
  }, [end]);
  return count;
};
// Use for: "500+ traders" → counts from 0 to 500 on scroll into view

PERFORMANCE RULES — NON-NEGOTIABLE

All animations use transform and opacity only — never animate width, height, top, left, margin (these cause layout reflow and kill performance)
Add will-change: transform only to the floating hero cards and the ticker — not globally
All animations must respect prefers-reduced-motion:

css@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

Floating hero cards: pause animation when tab is not visible (document.addEventListener('visibilitychange', ...))
Mouse parallax: throttle the mousemove handler to 60fps max using requestAnimationFrame
Ticker: use will-change: transform on the track element only
Card entrance animations: disconnect Intersection Observer after first trigger — do not leave observers running indefinitely


WHAT NOT TO ANIMATE

Do not animate layout shifts — no animating flex/grid changes
Do not use JS animation libraries (Framer Motion, GSAP, Lottie) — pure CSS and minimal React hooks only, keeping bundle size small
Do not animate the admin pages — those are functional tools, not marketing pages
Do not add animations to form inputs, error messages, or anything in the checkout/payment flow
Do not add infinite spinning loaders — use the skeleton shimmer from Step 12 instead
